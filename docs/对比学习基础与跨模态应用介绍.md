# 对比学习基础与跨模态应用介绍

## 1. 什么是对比学习

对比学习（Contrastive Learning）通过比较样本之间的关系学习表示。

核心思想：

- 相似样本表示接近
- 不相似样本表示远离

目标是学习具有语义结构的 embedding 空间。

---

## 2. 基本结构

```
Input
 |
Encoder
 |
Embedding
 |
Similarity
 |
Contrastive Loss
```

模型学习表示空间，使：

```
sim(positive) ↑

sim(negative) ↓
```

---

## 3. 正样本与负样本

正样本：语义相关的样本。

例如：

- 同一图片不同增强版本
- 图片和对应文本
- 不同语言中的相同含义文本

负样本：语义不相关样本。

---

## 4. SimCLR

SimCLR 是经典自监督对比学习方法。

结构：

```
Image
 |
Augmentation
 |
Encoder
 |
Projector
 |
Embedding
 |
NT-Xent Loss
```

目标：最大化同一图片不同视图之间相似度。

---

## 5. InfoNCE / NT-Xent Loss

公式：

```
L = -log(exp(sim(q,k+))/Σexp(sim(q,k)))
```

其中：

- sim 表示样本相似度，通常使用 cosine similarity；
- exp 将相似度转换为 softmax score；
- -log 将正确匹配概率转换为优化目标。

InfoNCE 本质上把检索问题转换为 batch 内分类问题。

---

## 6. CLIP 中的跨模态对比学习

CLIP 将对比学习用于图像-文本对齐：

```
Image Encoder → Image Projector → z_i

Text Encoder → Text Projector → z_t
```

训练：

最大化正确图片-文本对的相似度。

---

## 7. 低资源语言任务中的应用

低资源语言通常缺少大规模图文数据。

可以利用已有中文/英文视觉语言模型：

```
Low-resource Text
 |
Encoder
 |
Projector
 |
z_lr

与已有 image/text embedding 空间对齐
```

目标：让低资源语言进入已有多模态语义空间。

---

## 8. 常见优化方法

### Hard Negative

选择困难负样本，提高模型判别能力。

### Distillation

使用强模型作为 Teacher，引导弱模型学习。

### Multi-modal Alignment

同时优化：

- 文本-图片对齐
- 多语言文本对齐
- 不同模型表示一致性

---

## 总结

对比学习通过“拉近相似样本、推远不同样本”学习表示。

核心组件：

1. Encoder：提取特征；
2. Projector：映射到训练空间；
3. Similarity：衡量关系；
4. Contrastive Loss：优化表示结构。

CLIP、SigLIP 和多语言跨模态检索模型均采用这一思想。
